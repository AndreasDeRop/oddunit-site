PRIVACY

Privacybeleid

Laatst bijgewerkt op 13 september 2026. Dit beleid legt uit welke gegevens OddUnit Studio verwerkt wanneer je de website bezoekt of contact opneemt.

Wie verwerkt je gegevens?

OddUnit Studio verwerkt gegevens via deze website. Je kan ons bereiken via info@oddunit.be.

Welke gegevens verwerken we?

Wanneer je een formulier invult of ons mailt, verwerken we de gegevens die je zelf doorstuurt, zoals naam, e-mailadres, pakket, timing, projectinformatie en je bericht. Als je analytics accepteert, verwerken we ook beperkte website-statistieken.

Waarom gebruiken we die gegevens?

We gebruiken je gegevens om je vraag te beantwoorden, een samenwerking voor te bereiden, offertes of projectinformatie op te volgen en de website te verbeteren. Analytics gebruiken we alleen na toestemming.

Externe diensten

De website draait via Cloudflare Pages/CDN. Aanvraagformulieren worden doorgestuurd via FormSubmit naar ons e-mailadres. Het nieuwsbrief formulier wordt pas na jouw klik geladen via EmailOctopus en kan Google reCAPTCHA gebruiken. Google Analytics en Google Tag Manager laden alleen als je analytics accepteert in de cookiebanner.

Bewaartermijn

We bewaren contact- en projectgegevens zolang dat nodig is om je aanvraag op te volgen, een samenwerking uit te voeren of onze administratie correct te bewaren. Cookiekeuzes worden maximaal zes maanden onthouden.

Je rechten

Je kan vragen om inzage, correctie, verwijdering of beperking van je gegevens. Je kan analytics-toestemming altijd wijzigen via .

Klacht

Heb je een privacyvraag, mail ons eerst via info@oddunit.be. Je kan ook terecht bij de Belgische Gegevensbeschermingsautoriteit.
